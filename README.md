# Task Manager

A full-stack task management application built while learning backend and full-stack software engineering.

## Backend

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT authentication

## Frontend

- React
- Vite
- JavaScript

## Features

- User registration
- User login
- JWT authentication
- Create tasks
- View tasks
- Complete and uncomplete tasks
- Delete tasks
- Update task names
- Search tasks
- User-specific task ownership
